# جراج أبو يوسف — Backend (Laravel + MySQL)

الواجهة الخلفية (Backend API) لمتجر وخدمات **جراج أبو يوسف** المتخصص في موتوسيكلات Zontes في مصر.

---

## 1. المتطلبات والتشغيل المحلي

### أ) تشغيل خادم MySQL
- تأكد من تشغيل خادم **MySQL** من خلال لوحة تحكم XAMPP (`C:\xampp\xampp-control.exe`) على المنفذ الافتراضي `3306`.
- أنشئ قاعدة البيانات باسم `aygarage` وترميز `utf8mb4_unicode_ci`:
  ```sql
  CREATE DATABASE aygarage CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
  ```

### ب) إعداد ملف البيئة (.env)
- انسخ ملف `.env.example` إلى `.env`:
  ```bash
  cp .env.example .env
  ```
- ولّد مفتاح التطبيق:
  ```bash
  php artisan key:generate
  ```
- عيّن كلمات مرور البيانات الأولية التي تختارها بنفسك في ملف `.env` (إلزامية لعمل الـ Seeders، اختر كلمات مرور قوية من اختيارك):
  ```env
  SEED_ADMIN_PASSWORD=اختر_كلمة_مرور_المدير_هنا
  SEED_DEMO_PASSWORD=اختر_كلمة_مرور_العميل_هنا
  ```
- تأكد من ضبط قرص التخزين:
  ```env
  FILESYSTEM_DISK=public
  ```
- تفعيل رابط ملفات التخزين العامة:
  ```bash
  php artisan storage:link
  ```

### ج) بناء الجداول وتوليد البيانات الأولية (Migration & Seeding)
- قم بتشغيل الأمر التالي لإنشاء الجداول وحشو كل البيانات الأولية:
  ```bash
  php artisan migrate:fresh --seed
  ```
> **ملاحظة بخصوص أقسام المنتجات (Categories):**
> تعرض الواجهة وAPI الأقسام (`/api/categories`) عدد المنتجات الحقيقي الفعلي (`count`) المحسوب من قاعدة البيانات لكل قسم وليس أرقاماً وهمية.

### د) تشغيل السيرفر
- لتشغيل سيرفر الـ API المحلي على المنفذ `8000`:
  ```bash
  php artisan serve
  ```

## 4. القرارات المعمارية وقواعد العمل (Business Rules)
- **الموتوسيكلات المباعة (`status = 'sold'`):** عند طلب تفاصيل موتوسيكل مباع عبر `GET /api/bikes/{slug}`، يُرجع النظام تلقائياً كود `404 Not Found` ورسالة تفيد بأن الموتوسيكل غير موجود لمنع شراء أو حجز أو استعراض الدراجات المباعة كمعروضات نشطة، كما يتم استبعادها تماماً من القوائم العامة (`GET /api/bikes`).
- **توليد أرقام الطلبات المتتابعة (Sequential Order Numbers):** يتم توليد رقم الطلب التتابعي داخل المعاملة (Database Transaction) باستخدام قفل `Order::lockForUpdate()->selectRaw('MAX(CAST(number AS UNSIGNED))...')` لضمان عدم تكرار أرقام الطلبات ومنع التضارب أثناء الطلبات المتزامنة.

## 5. إعدادات الإنتاج (Production Deployment)
عند رفع النظام على بيئة الإنتاج:
1. **إيقاف وضع تصحيح الأخطاء:** يجب ضبط `APP_DEBUG=false` و `APP_ENV=production` في ملف `.env` لمنع ظهور أي تفاصيل أو Stack Trace للمستخدمين ولإرجاع ردود JSON واضحة ومترجمة.
2. **تقييد نطاقات CORS:** ضبط متغير `CORS_ALLOWED_ORIGINS` بنطاق الواجهة الأمامية الحقيقي فقط (مثال: `https://aygarage.com`) بدلاً من `*`.
3. **صلاحية الرموز (Sanctum Tokens):** تم ضبط صلاحية التوكن تلقائياً على 60 يوماً (`config/sanctum.php`).
